# TextClassifier
1. Classified Sentence using Embedding + ANN
2. Used Open AI ``text-embedding-ada-002`` model to generate the encodings of each sentence.
3. It is a encoder based model, used to capture the contextual relationships between words, effectively representing the overall meaning of the text.
4. Now the encoding is passed through Feed forward neural network layers, which is a classification model, to classify the texts.
To run the colaboratory, just download and run the colab files.
